# Fitness Session Logger

## Описание

Fitness Session Logger — приложение для ведения тренировок и отслеживания физической активности.

Пользователь может создавать тренировки, добавлять упражнения, фиксировать подходы, вес и количество повторений, а также просматривать историю тренировок и календарь посещений.

Проект разработан в рамках итогового задания по курсу iOS-разработки.

---

## Основные функции

### Тренировки

* Создание тренировки
* Редактирование тренировки
* Удаление тренировки
* Детальный экран тренировки
* Фильтрация по типу тренировки

### Упражнения

* Выбор упражнения из встроенной базы
* Добавление собственных упражнений
* Описание техники выполнения упражнения
* Указание сложности и группы мышц

### Подходы

* Добавление подходов
* Изменение веса
* Изменение количества повторений
* Подсчёт общего количества подходов

### Календарь

* Просмотр тренировок по дням
* Просмотр тренировок за выбранную дату
* Недельная сводка тренировок

### Дополнительные возможности

* Таймер тренировки
* Добавление фотографии к тренировке
* Анимация пустого состояния через Lottie

---

## Архитектура

Проект построен с использованием архитектуры MVVM.

### Model

Хранит данные приложения:

* WorkoutSession
* Exercise
* ExerciseSet
* LoggedExercise

### View

Отвечает за отображение интерфейса.

Основные экраны:

* Список тренировок
* Детальный экран тренировки
* Добавление тренировки
* Календарь тренировок
* База упражнений

### ViewModel

Отвечает за:

* загрузку данных
* сохранение данных
* фильтрацию тренировок
* поиск
* обработку действий пользователя

### Storage Layer

Для хранения данных используется отдельный слой хранения:

* FileWorkoutStorage
* CustomExerciseStorage

Данные сохраняются локально в JSON-файлы и восстанавливаются после перезапуска приложения.

### Service Layer

Используется сервисный слой для работы с упражнениями:

* ExerciseService
* MockExerciseService

MockExerciseService имитирует работу реального сервера и позволяет легко заменить источник данных на API в будущем.

## Swift Package Manager

Для выполнения требования SPM подключена библиотека Lottie.

Lottie используется для отображения анимации на экране пустого состояния приложения.

---

## UIKit + SwiftUI Integration

Для выбора фотографии тренировки используется UIKit-компонент PHPickerViewController.

Интеграция выполнена через UIViewControllerRepresentable.

---

## Локальное хранение

Данные сохраняются локально с помощью FileManager.

После перезапуска приложения сохраняются:

* тренировки
* пользовательские упражнения
* настройки приложения

## Тестирование

В проекте реализованы тесты для проверки:

* загрузки данных
* пустого состояния
* добавления тренировки
* фильтрации тренировок
* поиска
* восстановления данных из Storage

* XCTest

Product → Test

или

## Как запустить проект

1. Открыть проект в Xcode.
2. Дождаться загрузки Swift Package Manager зависимостей.
3. Выбрать симулятор.
4. Нажать Run (⌘ + R).
